# 开发约定

复核日期：2026-11-07。

## 目录与注释

产品、包、安装目录与发布产物使用 `mystia-steward-companion`，C#标识使用 `MystiaStewardCompanion`。新增代码包含规范中文注释，说明边界、失败条件、状态所有权和非显然原因，不重复语句字面含义。

Flutter应用按app/ui/features分层。DTO与协议放 `companion_protocol`，HTTP/设备权威/租约放 `companion_client`，Pigeon与Windows/Android适配放 `companion_platform`。独立updater位于 `native/updater`。页面不得直接创建HTTP客户端或重写C#业务算法。

### 中文注释规范

注释与代码一同维护，以帮助调用者正确使用接口、帮助维护者理解约束为目的，不以注释行数或覆盖率替代内容审查。

- C# 类型和重要接口使用 XML 文档注释，Dart 使用 Dartdoc，Rust 使用文档注释，JavaScript 使用 JSDoc；脚本按语言惯例说明用途、输入限制与副作用。保留版权和许可证声明。
- 接口注释说明职责、输入前提、返回值及失败含义；必要时补充状态所有权、线程要求、生命周期、时间单位和特殊值。简单字段或直接转发函数不机械重复标识符含义。
- 内部注释放在非显然判定附近，说明判定原因、约束来源、回退范围或修改时必须保持的不变量。区分“已请求”“已接受”“已持久化”“已执行”和“已确认”，不将预测结果、显示状态或隔离测试当作运行时事实。
- 修改注释前核对实现、调用方和相关测试。无法从当前代码或已核验资料确认的行为应明确限定范围，不使用“始终安全”“完全原子”“全局最优”等超出实现证据的表述。
- 生成代码的注释从输入定义维护并重新生成，检查生成一致性；冻结差分参考源码按其来源清单保留，不为统一注释破坏基线。测试注释说明夹具与断言证明的边界，不把替身描述成真实游戏对象。
- 公共注释和文档仅记录可共享的协议、类型、相对路径及资料入口，不写入本机用户名、私有目录、设备标识、凭据或临时调试记录。

仅注释修改也须检查差异和语法，防止块注释边界、文档引用、预处理指令或字符串夹具受到影响；按[验证指南](validation-guide.md)记录实际验证范围。

## Flutter 与 Dart

保持严格类型、不可变服务端值对象与显式nullable字段。展示缺失不能转成“业务确认无数据”；错误状态必须可见。布局以逻辑像素和约束为准，虚拟列表使用稳定身份，不用刷新时间作为key。

Widget局部状态保存筛选、焦点和编辑值，应用组合层保存会话与平台生命周期。中文输入不得在每次服务端刷新时重建controller或覆盖composing。异步写入明确等待，错误统一显示，不遗留未处理Future。

Forui负责一致控件和可访问性，animations只用于页面转换。各平台共享设计系统，平台特有行为通过能力判断开放。减少动效不得影响协议状态机。

控件高度、字号、间距、标签行、图片尺寸和弹层宽度使用项目共享组件与度量；先检查 `ui/` 中已有实现，再决定是否新增。页面不得靠局部缩放或填充补偿制造第二套规格，具体组件职责见[伴随窗口 UI](companion-ui.md)。仅改变文案不应修改稳定身份或重建编辑控件。

## C# 与运行时

两个业务模块为纯.NET6/C#10，不引用Unity、BepInEx、HTTP或客户端框架。游戏读取和副作用留在Mod适配层，Unity对象只在主线程访问；跨线程只能传不可变托管数据和精确标识。

未知状态、缺失集合、歧义身份和结果不确定时停止相关操作。不能按文本、位置、托管hash或固定延迟猜测。排队前、执行前及异步回执后均校验会话、代次与权威，真实运行时行为仍按相关专题要求验证。

## 协议、平台与存储

新客户端只支持当前成套协议，不保留旧客户端别名或旧协议回退。历史客户端偏好通过显式导入处理，原资料保留，新客户端身份独立；不能把客户端导入与 Mod 旧 CFG 的备份、迁移和自动清理混为同一过程。自动化只以持久化共享配置 `automationEnabled` 表达开关意图；新身份默认关闭，既有配置恢复仍须通过主设备、同步确认、租约与场景门禁。

存储位置由所属组件集中解析：Mod 使用统一配置根，内置 Windows 客户端使用每用户目录，独立 Windows 包使用 EXE 旁 `client-data/`，Android 使用应用私有目录。便携模式由专用 EXE 与完整清单确定，不能通过 cwd、连接地址或设备角色推断；写入前先完成目录准入与首次初始化。路径与迁移契约见[更新系统](update-system.md#数据与程序目录)及[独立客户端](standalone-client.md)。

扩展页签常驻，开关位于各模块内部。任务列表、稀客邀请、库存编辑使用本机持久化开关、默认关闭；历史任务/邀请开关可迁移，库存新增独立开关，已导入记录的补齐不能覆盖明确保存的关闭值。隐藏或禁用这些本机模块不得继续读取或发起游戏写入，异步确认返回时重新核对模块与页面状态。自动化和游戏界面辅助使用共享总开关，退出页签不改变效果；辅助总开关必须在 C# 执行侧生效，不能只隐藏配置控件或清空分项来模拟关闭。

租约acquire/release串行；POST不自动重放。配置同步使用CAS，先原子持久化并回读确认，再ACK。业务显示是否可保留与是否可以执行分别判定。

Windows 用 DPAPI、Android 用 Keystore 保护客户端凭据。损坏或当前用户环境无法解密时，保留原件并明确报错，不自动删除重建。真实 Token 不得进入普通客户端配置、日志、异常正文或测试证据；隔离测试使用公开合成凭据，不能读取本机正式配置。连接页显式编辑时可从安全存储回填并由用户主动显示，不代表允许将凭据写入日志。存储绝对位置只供本机设置页按需展开，不写入普通操作记录或业务请求。

## 交付与验证

工具版本以根 `toolchain.lock.json` 为准。完整 Mod 包用唯一 `package-manifest.json` 描述受管理载荷，独立 Windows 包另有自己的便携清单；两包校验相同来源的文件投影，拒绝路径穿越、链接、大小写冲突、多余文件及运行数据。受支持的在线更新与本地安装器执行整目录事务：先确认精确客户端进程退出，再替换并校验，失败恢复完整备份。公开 v1.3.1 首次手动删除旧插件目录不具备这项自动回滚保证，步骤见[更新系统](update-system.md#v131-手动首次升级)。

按[验证指南](validation-guide.md)选择检查，记录真实执行范围。用户可见行为变化时同步两份README与Flutter内置帮助；专题文档只保留当前规则。临时证据放temp，本地方案与交接放独立local-docs仓库。

整理提交历史前保留原提交引用，区分纯历史变换与同时进行的文件修改：纯压缩核对 Git tree 完全相同；附带文档整理时另核对文档差异白名单与其余文件的 blob/模式均不变。历史产物的 sourceCommit 不随 Git 整理而改写，后续构建必须重新生成自己的来源清单。
